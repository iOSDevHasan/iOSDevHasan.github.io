Game Drop Radar プライバシーポリシー

最終更新日：2026年10月16日

Game Drop Radar（以下「本アプリ」）は、Hasan Berat Gürbüz が開発した、期間限定の無料ゲーム配布のためのパーソナルレーダーです。本ポリシーでは、本アプリが扱う情報について説明します。

収集するデータ

Game Drop Radar は個人データを収集しません。ユーザーアカウント、広告、分析、トラッキングはなく、App Tracking Transparency の許可を求めることもありません。

デバイスに保存されるデータ

設定（プラットフォーム、ジャンル、プレイ時間、リマインダー）とライブラリ（ウィッシュリスト、積みゲー、入手済み・スキップしたゲーム）はデバイス上にのみ保存され、配布をデバイス内でスコアリングするために使われます。アプリを削除するとこれらのデータも削除されます。

配布情報のデータ

配布情報と画像は公開されている GamerPower API から取得します。これらのリクエストにはあなたの個人情報は含まれず、画像はパフォーマンスのためにデバイスにキャッシュされるだけです。

クラッシュレポート

安定性向上のため、本アプリは Google が提供する Firebase Crashlytics を使用します。クラッシュ時には、スタックトレース、アプリのバージョン、iOS のバージョン、デバイスモデル、ランダムなインストール ID などの技術的な診断情報が送信されます。レポートはあなたの身元と結び付けられず、トラッキングや広告には使われません。Google は Firebase の規約と Google プライバシーポリシーに従ってこれらのデータを処理します。

通知

期限が近い配布のリマインダーは、デバイス上でスケジュールされるローカル通知です。開発者のサーバーを経由しません。

Apple Intelligence

オプションのゲームメモは、Apple Intelligence によりデバイス上で非公開に生成されます。内容が開発者や第三者の AI サービスに送られることはありません。

購入

Game Drop Radar は App Store で販売される有料アプリで、サブスクリプション、App 内課金、広告はありません。支払いは Apple が自社のプライバシーポリシーに基づいて処理し、私たちが支払い情報を受け取ることはありません。

子どものプライバシー

本アプリは、子どもを含む誰からも意図的に個人データを収集しません。

本ポリシーの変更

本ポリシーを変更した場合は、新しい日付とともにこのページで公開します。

お問い合わせ

本ポリシーに関するご質問は、Hasan Berat Gürbüz（hasan.gurbuz11@hotmail.com）までお問い合わせください。
