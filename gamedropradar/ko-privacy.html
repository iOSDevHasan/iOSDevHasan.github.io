Game Drop Radar 개인정보 처리방침

최종 업데이트: 2026년 10월 16일

Game Drop Radar(이하 '앱')는 Hasan Berat Gürbüz가 개발한 기간 한정 무료 게임 증정용 개인 레이더입니다. 이 방침은 앱이 처리하는 정보를 설명합니다.

이 방침은 Game Drop Radar 1.1 버전부터 적용됩니다.

수집하는 데이터

Game Drop Radar는 개인 데이터를 수집하지 않습니다. 사용자 계정, 광고, 분석, 추적이 없으며 앱 추적 투명성 권한도 요청하지 않습니다.

기기에 저장되는 데이터

설정(플랫폼, 장르, 플레이 시간, 알림)과 라이브러리(위시리스트, 백로그, 받은 게임과 건너뛴 게임)는 기기에만 저장되며 증정을 기기에서 점수화하는 데 사용됩니다. 앱을 삭제하면 이 데이터도 삭제됩니다.

증정 정보 데이터

증정 목록과 이미지는 공개 GamerPower API에서 가져옵니다. 이 요청에는 사용자에 대한 개인 정보가 포함되지 않으며, 이미지는 성능을 위해서만 기기에 캐시됩니다.

충돌 보고서

안정성을 높이기 위해 앱은 Google의 Firebase Crashlytics를 사용합니다. 앱이 충돌하면 스택 추적, 앱 버전, iOS 버전, 기기 모델, 임의의 설치 식별자 같은 기술 진단 정보가 전송됩니다. 보고서는 사용자의 신원과 연결되지 않으며 추적이나 광고에 사용되지 않습니다. Google은 Firebase 약관과 Google 개인정보처리방침에 따라 이 데이터를 처리합니다.

알림

곧 끝나는 증정 알림은 기기에서 예약되는 로컬 알림이며 개발자 서버를 거치지 않습니다.

Apple Intelligence

선택 사항인 게임 노트는 Apple Intelligence로 기기에서 비공개로 생성됩니다. 어떤 내용도 개발자나 제3자 AI 서비스로 전송되지 않습니다.

구매

Game Drop Radar는 App Store에서 판매되는 유료 앱으로 구독, 앱 내 구입, 광고가 없습니다. 결제는 Apple이 자체 개인정보 처리방침에 따라 처리하며, 저희는 결제 정보를 받지 않습니다.

아동의 개인정보

앱은 아동을 포함한 누구에게서도 고의로 개인 데이터를 수집하지 않습니다.

방침 변경

이 방침이 변경되면 새 날짜와 함께 이 페이지에 게시됩니다.
