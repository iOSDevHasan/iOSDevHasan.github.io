นโยบายความเป็นส่วนตัวของ Game Drop Radar

อัปเดตล่าสุด: 16 ตุลาคม 2026

Game Drop Radar (“แอป”) คือเรดาร์ส่วนตัวสำหรับเกมแจกฟรีแบบจำกัดเวลา พัฒนาโดย Hasan Berat Gürbüz นโยบายนี้อธิบายว่าแอปจัดการข้อมูลใดบ้าง

ข้อมูลที่เราเก็บรวบรวม

Game Drop Radar ไม่เก็บข้อมูลส่วนบุคคล แอปไม่มีบัญชีผู้ใช้ โฆษณา การวิเคราะห์ หรือการติดตาม และไม่เคยขอสิทธิ์ความโปร่งใสในการติดตามของแอป

ข้อมูลที่จัดเก็บในอุปกรณ์ของคุณ

การตั้งค่าของคุณ (แพลตฟอร์ม แนวเกม เวลาเล่น และการเตือน) และคลังเกมของคุณ (รายการที่อยากได้ เกมค้างเล่น เกมที่รับแล้วและข้ามไป) จัดเก็บไว้ในอุปกรณ์ของคุณเท่านั้น และใช้ให้คะแนนข้อเสนอภายในเครื่อง การลบแอปจะลบข้อมูลเหล่านี้

ข้อมูลข้อเสนอ

รายการข้อเสนอและรูปภาพมาจาก GamerPower API แบบสาธารณะ คำขอเหล่านี้ไม่มีข้อมูลส่วนบุคคลของคุณ และรูปภาพจะถูกแคชในอุปกรณ์เพื่อประสิทธิภาพเท่านั้น

รายงานการขัดข้อง

เพื่อเพิ่มความเสถียร แอปใช้ Firebase Crashlytics ซึ่งเป็นบริการของ Google หากแอปขัดข้อง จะส่งข้อมูลวินิจฉัยทางเทคนิค เช่น stack trace เวอร์ชันแอป เวอร์ชัน iOS รุ่นอุปกรณ์ และรหัสการติดตั้งแบบสุ่ม รายงานไม่เชื่อมโยงกับตัวตนของคุณและไม่ใช้เพื่อการติดตามหรือโฆษณา Google ประมวลผลข้อมูลนี้ตามข้อกำหนดของ Firebase และนโยบายความเป็นส่วนตัวของ Google

การแจ้งเตือน

การเตือนข้อเสนอที่ใกล้หมดเป็นการแจ้งเตือนภายในเครื่องที่ตั้งเวลาไว้ในอุปกรณ์ของคุณ และไม่ผ่านเซิร์ฟเวอร์ของผู้พัฒนา

Apple Intelligence

บันทึกเกมแบบไม่บังคับสร้างขึ้นอย่างเป็นส่วนตัวในอุปกรณ์ของคุณด้วย Apple Intelligence ไม่มีเนื้อหาใดถูกส่งไปยังผู้พัฒนาหรือบริการ AI ของบุคคลที่สาม

การซื้อ

Game Drop Radar เป็นแอปแบบชำระเงินที่ขายใน App Store ไม่มีการสมัครสมาชิก การซื้อภายในแอป หรือโฆษณา Apple จัดการการชำระเงินตามนโยบายของตน เราไม่เคยได้รับข้อมูลการชำระเงินของคุณ

ความเป็นส่วนตัวของเด็ก

แอปไม่ได้จงใจเก็บข้อมูลส่วนบุคคลจากผู้ใด รวมถึงเด็ก

การเปลี่ยนแปลงนโยบาย

หากนโยบายนี้เปลี่ยนแปลง ฉบับปรับปรุงจะเผยแพร่ในหน้านี้พร้อมวันที่ใหม่
