Kebijakan Privasi Game Drop Radar

Terakhir diperbarui: 16 Oktober 2026

Game Drop Radar (“aplikasi”) adalah radar pribadi untuk game gratis berwaktu terbatas, dikembangkan oleh Hasan Berat Gürbüz. Kebijakan ini menjelaskan informasi apa saja yang ditangani aplikasi.

Kebijakan ini berlaku untuk Game Drop Radar mulai versi 1.1.

Data yang Kami Kumpulkan

Game Drop Radar tidak mengumpulkan data pribadi. Aplikasi ini tidak memiliki akun pengguna, iklan, analitik, maupun pelacakan, dan tidak pernah meminta izin Transparansi Pelacakan Aplikasi.

Data yang Disimpan di Perangkat Anda

Preferensi Anda (platform, genre, waktu bermain, dan pengingat) serta pustaka Anda (wishlist, backlog, game yang diklaim dan dilewati) hanya disimpan di perangkat Anda dan digunakan untuk menilai promo secara lokal. Menghapus aplikasi akan menghapus data ini.

Data Promo

Daftar promo dan gambar berasal dari API publik GamerPower. Permintaan ini tidak berisi informasi pribadi tentang Anda, dan gambar hanya di-cache di perangkat demi performa.

Laporan Kerusakan

Untuk meningkatkan stabilitas, aplikasi menggunakan Firebase Crashlytics, layanan dari Google. Jika aplikasi mogok, aplikasi mengirim data diagnostik teknis seperti stack trace, versi aplikasi, versi iOS, model perangkat, dan ID instalasi acak. Laporan tidak dikaitkan dengan identitas Anda dan tidak digunakan untuk pelacakan atau iklan. Google memproses data ini sesuai ketentuan Firebase dan Kebijakan Privasi Google.

Notifikasi

Pengingat untuk promo yang akan berakhir adalah notifikasi lokal yang dijadwalkan di perangkat Anda dan tidak melalui server milik pengembang.

Apple Intelligence

Catatan game opsional dibuat secara pribadi di perangkat Anda dengan Apple Intelligence. Tidak ada konten yang dikirim ke pengembang atau layanan AI pihak ketiga.

Pembelian

Game Drop Radar adalah aplikasi berbayar yang dijual di App Store, tanpa langganan, pembelian dalam aplikasi, atau iklan. Apple memproses pembayaran sesuai kebijakan privasinya; kami tidak pernah menerima detail pembayaran Anda.

Privasi Anak

Aplikasi ini tidak dengan sengaja mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan Kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal baru.
